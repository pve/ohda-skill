# ohda-skill

Claude Code skill formalizing Peter van Eijk's OHDA troubleshooting method
(Observe / Hypothesize / Decide / Act) — an active loop plus a replayable
worklog convention for non-trivial technical diagnosis sessions.

Source material: "Professional IT troubleshooting, simplified" (Club Cloud
Computing) — see `SKILL.md` for the full method and worklog conventions.
